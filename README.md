# SO_NHAT_KY_DAT

Tool lọc dữ liệu DAT theo học viên, lập sổ nhật ký giảng dạy / sổ TDTH ô tô (Bstđ, Bss, C1), kiểm tra hoàn thành khóa học.

- Mở: https://hp-wukoong.github.io/SO_NHAT_KY_DAT/
- Cài như ứng dụng: mở link bằng Chrome/Edge → biểu tượng "Cài đặt" trên thanh địa chỉ.
- Chạy được khi không có mạng (sau lần mở đầu tiên). Có mạng thì tự cập nhật bản mới.
- Dữ liệu học viên, DAT, thói quen chỉ lưu trên trình duyệt của máy đang dùng, không gửi lên mạng.
